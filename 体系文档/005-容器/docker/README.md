# Docker 工具手册

> **一句话**：单机容器的运维手册——镜像与容器、构建与优化、数据持久化、Compose 编排、网络与隔离底层、运行时进阶。  
> **读者**：在单机上管容器的运维；正在为 K8s（`../k8s/`）打地基的初学者。  
> **口径**：Docker CE 24+ / overlay2；示例均可 `docker run` 复现。  
> **更新**：2026-11-08  
> **术语表**：Docker 专有词见 [00 术语表](00-术语表.md)；领域词与跨册导航见板块级 [../00 术语表](../00-术语表.md)。

## 体系总览

六册一条主线：**先会跑（001），再会造（002），数据留得住（003），一组容器管得住（004），底层看得透（005/006）**。

| 册 | 解决的问题 |
| --- | --- |
| [001 镜像与容器](001-镜像与容器.md) | 镜像怎么变成容器；分层/overlay2/init 层/生命周期/PID 1 与信号 |
| [002 Dockerfile 与镜像构建](002-Dockerfile与镜像构建.md) | 镜像怎么造、怎么瘦：指令/缓存/多阶段/scratch/history 反推 |
| [003 数据卷与持久化](003-数据卷与持久化.md) | 数据放哪才不会随容器消失 |
| [004 Compose 与日常运维](004-Compose与日常运维.md) | 一组容器的编排、日志轮转、资源限制、磁盘巡检 |
| [005 Docker 网络与隔离底层](005-Docker网络与隔离底层.md) | 五种网络模型、端口转发的 iptables 链路、namespace/cgroup 手工实验 |
| [006 运行时进阶：containerd 与 ctr](006-运行时进阶：containerd与ctr.md) | 运行时栈实体化：containerd 部署、ctr 三层模型、与 K8s 的 CRI 关系 |

> **与「Linux」002 的衔接**：namespace/cgroup 的内核底子在 Linux 册 §2，本线 005 册是它的容器场景实验课。

## 阅读约定

1. **顺序**：001~004 是主线，005/006 是底层进阶——排障要用时再读也不迟。
2. **给输出**：命令都给预期输出，靠输出判断自己对不对。
3. **危险操作先说后果**：`prune` 家族、`--force` 一律先写会丢什么。
4. **每册结构统一**：目录 → 正文 → 坑表 → 检查清单 → 尾链。
