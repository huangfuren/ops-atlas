## 阅读约定

1. **每册结构统一**：目录 → 正文（每节开头一句承接上文）→ 坑表 → 检查清单 → 尾链。
2. **只写防御，不写攻击**：涉及攻击面时只描述"现象与防线"，不提供利用细节。
3. **每条加固措施给验证方法**——没有验证的加固等于没做。
4. **危险操作 ⚠️ 标注**：防火墙策略与 SSH 加固都可能把自己锁在门外——回滚路径必写。
