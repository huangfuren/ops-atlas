# 00 术语表

> **这一文档回答**：AI 运维词汇的准确定义、两个混用词的分界、「症状出现时病根在哪层」往哪走。  
> **怎么用**：按册分组（按名字）、按缩写（缩写速查）、按症状（症状反查）。  
> **只有一句话**：要落地动作回对应册；这里保证「认得出、分得清、找得到」。

## 按册分组

| 术语 | 英文 | 一句话 |
|---|---|---|
| AI 运维工程化 | AI Ops Engineering | 把 AI 的行为、技能、连接、授权、交付全部工程化 |

### 003 MCP 接入与受管调用

| 术语 | 英文 | 一句话 |
|---|---|---|
| MCP | Model Context Protocol | 工具连接协议：tools/resources 标准化 |

### 004 AI 批量操作安全

| 术语 | 英文 | 一句话 |
|---|---|---|
| 只读默认 | Read-only Default | 数据面入口默认只发 SELECT 类 |
| 授权三件套 | Write Triple | `--write --authorized-by --reason` 缺一即拒 |
| 永不放行 | Never Allowlist | DDL/权限/搬运/锁类即使授权也结构化拒绝 |
| 确认码 | Confirmation Code | 批量发包前使用者回带码确认语，AI 不得代填 |
| 写库三步 | Three-step Write | backup → 试算（不带 execute）→ 授权后 execute |
| 补扫校验 | Verify & Fix | 批量扫描后对漏扫目标点名补扫 |
| 凭据红线 | Credential Red Line | 值不进对话；true/false 通道；缺了给命令 |

## 最容易混的 10 对

| A vs B | 分界一句话 |
|---|---|
| Agent vs Harness | Agent 是干活的实体；Harness 是它跑起来的运行时 |
| Skill vs MCP | Skill 管"怎么处理"；MCP 管"怎么连" |
| 宪法 vs 刑法 | 宪法是最高准则；刑法是一票否决的禁令层 |
| 临时凭证 vs 永久凭证 | 网关自签短时；身份服务长期——失败时动作相反 |
| 受管调用 vs 直连 | 走规约+索引+时序；绕过即违规，无例外 |
| 项目记忆 vs 工具私产 | 随仓走的是资产；换工具即丢的是私产 |
| prompt vs 规约 | prompt 管一次对话；规约管所有对话 |
| 只读默认 vs 写授权 | 默认态与例外态；写必须三件套参数化 |
| 幂等 vs 重试 | 幂等是"重复执行无害"的性质；重试是动作——先幂等再重试 |
| 版本路由 vs 写死路径 | 路由跟声明走；写死即绕过管理 |

## 按症状反查

| 症状 | 最可能病根 | 去哪 |
|---|---|---|
| 换个工具 AI 就"不守规矩" | 规约没进仓库，只在会话里 | 001 §1.1 |
| AI 把日志"润色"得面目全非 | 越过归位边界改写事实 | 001 §1.2 |
| 工具读不到技能 | 软链接断/绝对路径/目录名不符 | 002 §2.2 |
| AI 开工就报缺环境 | 没跑 init 前置检查包 | 002 §2.3 |
| 调用报 403 credential_invalid | 临时凭证过期/跨入口 | 003 §3.5 |
| AI 反复索要密码 | 凭据通道被绕过 | 004 §4.5 |
| 写操作事后查不到谁授权 | 没走三件套 | 004 §4.1 |
| 批量扫描结论有洞 | 没跑补扫校验 | 004 §4.3 |
| 使用方 clone 后跑不起来 | 六件套读取顺序被跳过 | 005 §5.3 |
| 同一能力结果时好时坏 | 默认路由进了开发版 | 005 §5.5 |
