# 云平台手册

> **定位**：上云之后运维管什么——云上网络、主机、数据、IaC 与观测的体系文档，主线阿里云、AWS 对照注记。001~003 总览三件套管领域全景，011~015 正文五册按「网络 → 主机 → 数据 → IaC → 观测」排布——每一册对应一类云资源任务。  
> **读者**：要上云、已上云、负责云资源管理的运维/SRE。  
> **口径**：概念以云厂商通用模型为准（VPC/ECS/RDS/OSS 等命名以阿里云为参照，AWS 对照注记）；控制台界面迭代快，**以概念与 CLI/API 为准**；IaC 用 Terraform 1.x。  
> **更新**：2026-11-25  
> **术语表**：单独成册 → [190 术语表](190-术语表.md)。27 个术语 · 8 个缩写 · 10 对易混 · 10 条症状反查。

## 阅读约定

1. **每册结构统一**：目录 → 正文（每节开头一句承接上文）→ 坑表 → 检查清单 → 尾链。
2. **概念优先**：控制台截图会过期，CLI/API 与概念不过期——写法以 CLI 为准。
3. **AWS 对照注记**：核心术语给 AWS 对应名（如 ECS↔EC2），便于跨云迁移阅读。
