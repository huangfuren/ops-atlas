## 1. VPC：云上私有网络的底座

VPC 是你的**专属三层网络**，一切云资源（ECS/RDS/SLB）都必须落在一个 VPC 里。三层结构：

| 层 | 术语 | 要点 |
|---|---|---|
| VPC | 私有网络 | 指定一个私网网段（如 10.0.0.0/16）——**规划时留够余量**，VPC 网段创建后不可改 |
| 交换机 | vSwitch/subnet | VPC 内的子网，**绑定一个可用区**——跨 AZ 高可用 = 至少两个交换机各在不同 AZ |
| 路由表 | route table | 决定流量走向：默认同 VPC 内互通；跨 VPC/上公网/连 IDC 靠自定义路由 |

规划纪律：**生产/测试/管理分网段**（如 10.0.1.0/24 生产、10.0.2.0/24 测试），网段互不重叠（要打通 IDC 就不能与公司内网冲突）——这是事后最难改的决策。

## 2. 安全组：实例级有状态防火墙

安全组是**实例级的虚拟防火墙**，规则是白名单（默认拒绝一切入方向）：

| 特性 | 说明 |
|---|---|
| 有状态 | 入方向放行的连接，响应流量自动放行——**不用配回程规则** |
| 实例级 | 一台实例可挂 2~5 个安全组，规则叠加取并集 |
| 引用组 | 规则的源可以写另一个安全组（如 SLB 安全组 → 应用安全组）——网段变化不用改规则 |

对照自建（「网络」007）：安全组没有端口转发与 NAT 能力（那是 NAT 网关的事），也没有"日志"——审计靠 VPC 流日志（付费）。

运维纪律：**分层建组**（slb-sg 只放 80/443、app-sg 只接受 slb-sg 来源、db-sg 只接受 app-sg 来源）——链式最小暴露，拒绝"一台实例挂一个全通安全组"。

## 3. 公网入口：EIP 与 SLB

| 资源 | 语义 | 什么时候用 |
|---|---|---|
| 公网 IP | 实例自带，随实例生死 | 单台测试机 |
| **EIP**（弹性公网 IP） | 独立的公网资源，可绑定/解绑/漂移 | 高可用入口、换机不换 IP |
| **SLB**（负载均衡） | 流量入口分发到多台后端，自带健康检查 | 生产入口标配（七层/四层） |

生产入口的标准形态：**域名 → SLB（挂证书）→ 应用安全组内的多台 ECS**——证书统一在 SLB 卸载，后端实例不暴露公网（对照自建：SLB ≈ 接入层 Nginx/HAProxy 的云托管版，「接入层」006 的调度与健康检查概念通用）。

## 4. NAT 网关：私网出公网

纯内网的实例要升级补丁/拉依赖：**NAT 网关（SNAT）** 提供"出得去、进不来"的统一公网出口——比给每台实例绑 EIP 安全且省钱（共享带宽包）。对照组件：自建的 SNAT 网关（「网络」007 §NAT 三形态中的 SNAT）。

## 5. 与自建网络的对照

| 云上 | 自建对应（「网络」007/008） | 差异点 |
|---|---|---|
| VPC/交换机 | 二层交换机 + 三层网段规划 | 网段创建后不可改——先规划后建 |
| 安全组 | iptables/firewalld | 有状态、白名单、组引用；无 NAT |
| NAT 网关 | SNAT 网关 | 托管、带带宽包 |
| SLB | LVS/Nginx | 托管健康检查与证书卸载 |
| 流日志 | tcpdump | 全量付费采集——排障兜底 |

## 6. 坑表

| # | 坑 | 后果 | 正确做法 |
|---|---|---|---|
| 1 | VPC 网段拍脑袋（/16 全用了） | 要连 IDC 时地址冲突，只能重建 | 先拿公司内网地址规划表再定 VPC 网段 |
| 2 | 单 AZ 部署 | AZ 故障 = 业务全不可用 | 生产至少跨 2 AZ 各放一台 |
| 3 | 安全组全通（0.0.0.0/0 开所有端口） | 面向全网的攻击面 | 链式最小暴露：slb→app→db |
| 4 | 证书挂在每台 ECS 上 | 续期要逐台改 | 证书统一挂 SLB 卸载 |
| 5 | 出公网给每台绑 EIP | IP 散乱、成本高 | NAT 网关 + 统一 SNAT 出口 |
| 6 | 内网依赖走公网端点 | 流量费暴涨 + 绕出安全边界 | 同 Region 用内网端点（OSS/RDS 内网域名） |
