# 00 术语表

> **这一文档回答**：云平台领域的词是什么意思、两个混用词的分界、「只知道现象不知道翻哪册」往哪走。  
> **怎么用**：按名字（按主题分组）、按缩写（缩写速查）、按现象（症状反查）。  
> **只有一句话**：要操作细节回对应册；这里只保证你「认得出、分得清、找得到」。

## 01 概念与分层

| 术语 | 英文 | 一句话 |
|---|---|---|
| 云计算 | cloud computing | 资源池化 + 按需自服务 + 按量计费——IaaS/PaaS/SaaS 三层 |
| IaaS | Infrastructure as a Service | 卖"机器与网络"：计算/存储/网络资源，OS 以上归你 |
| PaaS | Platform as a Service | 卖"运行平台"：托管数据库/中间件，应用与数据归你 |
| 区域 | region | 云的物理地域（如 cn-hangzhou）——延迟与合规的边界 |
| 可用区 | Availability Zone, AZ | 同区域内物理隔离的机房——高可用部署的最小跨度和单位 |
| 责任共担 | shared responsibility | 云厂商管"底层设施"，你管"数据与配置"——本板块反复出现的分界 |

## 02 网络与交付

| 术语 | 英文 | 一句话 |
|---|---|---|
| VPC | Virtual Private Cloud | 云上私有网络：你的专属三层网络，实例与托管服务的底座 |
| 交换机 | vSwitch / subnet | VPC 内的子网（对应可用区），决定实例放哪个 AZ |
| 路由表 | route table | 决定 VPC 内流量走向——自建 IDC 互通靠自定义路由 |
| 安全组 | security group | 实例级**有状态**虚拟防火墙——云上的"iptables 平替" |
| NAT 网关 | NAT Gateway | 私网实例统一出公网的出口（SNAT）|
| SLB / CLB | Server Load Balancer | 云负载均衡（四层/七层）——对应自建的 LVS/Nginx |
| ECS | Elastic Compute Service | 云主机（AWS 对照：EC2） |
| 镜像 | image | 实例的启动模板：系统盘初始状态 |
| 快照 | snapshot | 云盘的时间点副本——增量存储，可回滚可做镜像 |
| 释放 | release | 实例销毁且**不再计费**——系统盘数据随释放消失 |

## 03 数据与 IaC

| 术语 | 英文 | 一句话 |
|---|---|---|
| RDS | Relational Database Service | 托管关系型数据库——备份/高可用厂商接管，SQL 归你 |
| OSS | Object Storage Service | 对象存储（AWS 对照：S3）——按 key 存取，容量无限 |
| 生命周期规则 | lifecycle rule | OSS 按前缀/时间自动转存储类或删除——日志成本的开关 |
| IaC | Infrastructure as Code | 用代码声明资源：可评审、可回滚、可重建 |
| Terraform | — | 主流 IaC 工具：HCL 声明资源，plan 预览，apply 落地 |
| state | terraform.tfstate | Terraform 的"账本"——真实资源与代码的映射，必须妥善保管 |

## 04 观测与成本

| 术语 | 英文 | 一句话 |
|---|---|---|
| 云监控 | Cloud Monitor | 云产品指标的自带采集——与自建 Prometheus 衔接（005） |
| 操作审计 | ActionTrail / CloudTrail | 控制台与 API 操作的日志——云上的"谁改了什么" |
| 预留实例 | reserved instance | 包年包月折扣形态——与按量计费的成本取舍 |
| 按量计费 | pay-as-you-go | 用多少付多少——测试与突发友好，长期跑更贵 |
| 账单分账 | cost allocation | 按标签/产品拆分账单——成本归属与优化入口 |

## 最容易混的 10 对

| 容易混 | 一句话差别 | 去哪 |
|---|---|---|
| 安全组 vs 防火墙 | 安全组是实例级有状态白名单；主机防火墙是系统级规则——**双层都要管** | 001 §2 |
| 区域 vs 可用区 | 区域是地理城市；可用区是城内机房——同区域跨 AZ 做高可用 | 000 §1 |
| 释放 vs 停机 | 释放=销毁不再计费、系统盘可能消失；停机=关机（按量可停机不计费） | 002 §3 |
| 快照 vs 备份 | 快照是云盘时间点副本（单盘）；备份是带策略的完整恢复能力（RDS） | 003 §2 |
| 镜像 vs 快照 | 镜像用于**创建**实例；快照用于**保存/回滚**云盘 | 002 §2 |
| 公网 IP vs EIP | 公网 IP 随实例生死；EIP 独立资源可解绑漂移 | 001 §3 |
| RDS vs 自建 MySQL | RDS 接管高可用/备份/打补丁；SQL/索引/容量仍是你的 | 003 §1 |
| OSS vs NAS | 对象存储按 key 单文件语义；NAS 是文件系统挂载 | 003 §3 |
| plan vs apply | plan 只预览变更；apply 真正落地——**永远先 plan** | 004 §3 |
| state vs 代码 | 代码是期望；state 是现实映射——丢了 state 等于丢了资源台账 | 004 §4 |

## 按症状反查

| 现象 | 大概率病根 | 去哪 |
|---|---|---|
| 实例之间 ping 不通 | 安全组没放行 / 不在同一 VPC | 001 §2 |
| 公网访问不了服务 | 安全组入方向 / SLB 监听 / EIP 未绑定 | 001 §3 |
| 释放实例后数据没了 | 系统盘随释放删除——重要数据先做快照 | 002 §3 |
| RDS 慢，但"机器"看起来很闲 | SQL 与索引归你管——看慢日志（RDS 接管的是机器不是 SQL） | 003 §1 |
| OSS 流量费暴涨 | 公网流出计费——改走内网端点或加 CDN | 003 §3 |
| terraform apply 把资源改没了 | state 与现实漂移——先 plan 审查 | 004 §3 |
| 误删了云资源想找回 | 操作审计定位 + 快照/备份恢复 | 005 §2 |
| 账单比预期高一倍 | 按量资源泄漏（EIP/快照/流量）——分账单排查 | 005 §4 |
| AZ 单机房故障大面积不可用 | 应用没做跨 AZ 部署 | 000 §2 |
| 想重现一个月前的配置 | 操作审计（ActionTrail）有完整 API 记录 | 005 §2 |
