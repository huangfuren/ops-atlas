# 00 术语表

> **这一文档回答**：虚拟化领域的词是什么意思、两个混用词的分界、「只知道现象不知道翻哪册」往哪走。  
> **怎么用**：按名字（按主题分组）、按缩写（缩写速查）、按现象（症状反查）。  
> **只有一句话**：要操作细节回对应册；这里只保证你「认得出、分得清、找得到」。

## 01 概念与架构

| 术语 | 英文 | 一句话 |
|---|---|---|
| 虚拟机 | Virtual Machine, VM | 有完整虚拟硬件的"软件机器"——与容器的进程级隔离相对 |
| Hypervisor | — | 虚拟机监控器：类型 1 裸金属（ESXi/KVM），类型 2 宿主上（Workstation） |
| 宿主机 | host | 跑 hypervisor 的物理机 |
| 客户机 | guest | 跑在 hypervisor 里的虚拟机 |
| vCenter | — | VMware 的集中管理平台：集群/资源池/模板的管家 |
| ESXi | — | VMware 的裸金属 hypervisor |
| libvirt | — | KVM 生态的管理层与 API：virsh/virt-manager 都走它 |
| QEMU | Quick Emulator | KVM 的设备模拟与用户态组件——与 KVM 内核模块合称完整虚拟化 |

## 02 资源与交付

| 术语 | 英文 | 一句话 |
|---|---|---|
| vCPU | virtual CPU | 虚拟机的逻辑 CPU——vCPU 总数超物理核叫超分 |
| 超分 | overcommit | 分配的资源总量超过物理实际量——内存超分靠 ballooning 兜底 |
| Ballooning | — | 内存气球：hypervisor 从闲置 VM"收回"内存给急需的 VM |
| 快照 | snapshot | 虚拟机某时刻的状态副本——**不是备份**（依赖母盘） |
| 模板 | template | 只读的虚拟机母版——克隆出标准新机 |
| 克隆 | clone | 从 VM/模板复制出新虚拟机（linked clone 依赖母盘） |
| vMotion | — | VMware 在线迁移：虚拟机不停机换宿主机（KVM 对应 live migration） |
| DRS | Distributed Resource Scheduler | 集群资源自动均衡——按规则在主机间摆 VM |
| HA（VMware） | High Availability | 主机故障后 VM 在其他主机自动重启 |

## 03 存储与网络

| 术语 | 英文 | 一句话 |
|---|---|---|
| VMDK | Virtual Machine Disk | VMware 虚拟磁盘格式 |
| qcow2 | QEMU Copy On Write | KVM 主流磁盘格式：写时复制、支持快照 |
| Thick/Thin 置备 | thick/thin provisioning | 一次性占满空间 / 用多少占多少（性能差异） |
| Datastore | — | VMware 的存储容器（VMFS/NFS） |
| 存储池 | storage pool | KVM 的存储容器（目录/LVM/网络） |
| vSwitch | virtual switch | VMware 虚拟交换机——VM 网络的枢纽 |
| 网桥 | bridge | KVM 的二层交换（Linux bridge 或 OVS）——VM 获得与宿主同网段 IP |
| SR-IOV | Single Root I/O Virtualization | 网卡硬件直通虚拟化——高性能网络场景绕过虚拟交换 |

## 缩写速查

| 缩写 | 全称 | 意思与出处 |
|---|---|---|
| VM | Virtual Machine | 虚拟机（全册） |
| HA | High Availability | VMware 故障自动重启（001） |
| DRS | Distributed Resource Scheduler | 资源自动均衡（001） |
| VMDK | Virtual Machine Disk | VMware 磁盘格式（001） |
| OVA/OVF | Open Virtualization Appliance/Format | 虚拟机打包交换格式（001） |
| qcow2 | QEMU Copy On Write v2 | KVM 磁盘格式（002） |
| PCI | Peripheral Component Interconnect | 直通（passthrough）涉及的设备总线（002） |
| NUMA | Non-Uniform Memory Access | 非统一内存访问——大 VM 的 CPU/内存亲和（002） |

## 最容易混的 10 对

| 容易混 | 一句话差别 | 去哪 |
|---|---|---|
| 快照 vs 备份 | 快照依赖母盘（链式，母坏全坏）；备份是独立副本 | 001 §2 · 002 §3 |
| Thick vs Thin 置备 | 一次占满（性能稳）/ 按需增长（省空间有开销） | 001 §4 |
| 全量 vs 链接克隆 | 独立完整 / 依赖母盘省空间——母盘升级影响所有链接克隆 | 001 §3 |
| 类型 1 vs 类型 2 hypervisor | 裸金属 / 装在 OS 上——生产用类型 1 | 000 §1 |
| vSwitch 标准版 vs 分布式版 | 单机配置 / vCenter 集中配置跨主机一致 | 001 §4 |
| 桥接 vs NAT（KVM 网络） | VM 同网段独立 IP / 借宿主机地址转换出网 | 002 §3 |
| 冷迁移 vs 热迁移 | 关机搬 / 在线 vMotion/live migration | 001 §2 · 002 §4 |
| ESXi vs vCenter | 单机 hypervisor / 管理多台的平台 | 001 §1 |
| KVM vs QEMU | 内核加速模块 / 设备模拟进程——合起来才是完整 VM | 002 §1 |
| 模拟 vs 半虚拟化 virtio | QEMU 全模拟（慢）/ virtio 专用驱动（快） | 002 §2 |

## 按症状反查

| 现象 | 大概率病根 | 去哪 |
|---|---|---|
| 虚拟机越来越慢但负载不高 | 快照链过长或内存超分 | 001 §2 · 002 §3 |
| 存储瞬间打满 | Thin 置备膨胀或快照链增长 | 001 §4 |
| vMotion/迁移卡住或失败 | CPU 特性不兼容 / 网络带宽不足 | 001 §2 · 002 §4 |
| KVM 虚拟机网络不通 | 网桥/防火墙/端口配置 | 002 §3 |
| ESXi 主机失联但 VM 还在跑 | vCenter/管理网络故障 | 001 §1 |
| 新建 VM 性能远低于预期 | 用了模拟设备而非 virtio | 002 §2 |
| 宿主机内存告急但 VM"没跑满" | 超分+ballooning 的隐性回收 | 001 §5 |
| 快照删除后磁盘反而变满 | 合并过程需要等量临时空间 | 001 §2 |
| VM 时间漂移 | 时钟源/同步服务未配 | 002 §2 |
| 集群 HA 没有触发重启 | 准入控制/资源预留不足 | 001 §5 |
