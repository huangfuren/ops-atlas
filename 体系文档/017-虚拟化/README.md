# 虚拟化手册

> **一句话**：虚拟化层的体系文档——VMware vSphere、KVM、PVE 三大主流的运维手册，容器脚下的地基。  
> **读者**：管理企业虚拟化环境（ESXi 集群/KVM 宿主机/PVE 集群）的运维；容器运维想搞懂"容器跑在哪"的底层。  
> **口径**：VMware 以 vSphere 8.x / vCenter 为准；KVM 以 libvirt/QEMU 生态为准（virsh 主线）；PVE 以 8.x（Debian 底座）为准；不写厂商许可商务细节。  
> **更新**：2026-11-08  
> **术语表**：单独成册 → [00 术语表](00-术语表.md)。30 个术语 · 8 个缩写 · 10 对易混 · 10 条症状反查。

## 体系总览

两大流派一册一个，外加打包平台：**VMware 是企业存量王者（商业全家桶），KVM 是开源与云上的底座，PVE 把 KVM+LXC 打包成开箱平台**——概念互通，工具不同。完整地图见 [000 虚拟化全貌](000-虚拟化全貌.md)（含架构图）。

> **与「容器」的分界**：容器跑在虚拟机里——虚拟机是"给容器一个安全的家"；两层排障思路不同（容器看 namespace，虚拟机看 hypervisor）。  
> **与「云平台」的分界**：云主机（ECS/EC2）就是托管虚拟机——002 的 KVM 概念是理解云主机的底座。

## 阅读约定

1. **每册结构统一**：目录 → 正文（每节开头一句承接上文）→ 坑表 → 检查清单 → 尾链。
2. **两大流派对照着学**：概念一一对应（vCenter↔libvirt、vMotion↔live migration、快照纪律相同）。
3. **每条运维操作给验证命令**——没有验证的变更等于没做。
