## 阅读约定

1. **每册结构统一**：目录 → 正文（每节开头一句承接上文）→ 坑表 → 检查清单 → 尾链。
2. **先读 000**：缓存层级与"可丢/不可丢"判定是全板块的地基。
3. **文字引用不带前缀**：写「Redis」003 而不是「014-Redis」003。
4. **配图两必**：改完必渲染、渲染必目视（PNG 不落盘，全库只留 SVG）；图片一律 `![]()` 嵌入。
