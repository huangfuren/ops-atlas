# Go 语言手册

> **一句话**：从装环境到定位生产事故的 Go 教材——000 全貌 + 三条能力线十七册。  
> **读者**：会 Shell 与 Python（「Linux」008、「Python」001 水平）的运维，第一次系统学 Go。  
> **口径**：Go 1.22+（module 模式）；标准库优先；示例均可 `go run`。  
> **更新**：2026-11-06  
> **术语表**：单独成册 → [00 术语表](00-术语表.md)。37 个术语 · 4 个缩写 · 12 对易混 · 10 条症状反查。

## 阅读约定

1. **Windows 为主线**：001 以 PowerShell 命令为主，Linux 命令有注记。
2. **所有示例可直接跑**：`go run` 即出结果，不依赖未介绍的包。
3. **错误处理不省略**：`if err != nil` 完整保留。
4. **每册结构统一**：目录 → 正文（每节开头一句承接上文）→ 坑表 → 检查清单 → 尾链。
