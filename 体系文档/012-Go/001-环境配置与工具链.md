## 1. 装什么

| 组件 | 必需 | 作用 |
|---|---|---|
| **Go SDK** | 必须 | 编译器、标准库、`go` 命令、测试框架、pprof |
| **编辑器** | 建议 | 补全、跳转、断点调试 |
| **gcc** | 可选 | 只有 `go test -race` 需要 |

**不需要装**：测试框架（`go test` 内置）、包管理器（`go mod` 内置）、`GOPATH` 工作目录（module 模式已废弃这个用法）、`GO111MODULE`（默认开启）。

## 2. 安装 Go

### 2.1 下载安装

1. 打开 https://go.dev/dl/ ，下载 **`go1.xx.windows-amd64.msi`**（列表最上面就是最新稳定版）
2. 双击，一路 Next。**路径保持默认 `C:\Program Files\Go`，不要改**
3. **关掉所有终端重新打开**（PATH 是启动时的快照，不重启会 `command not found`）

### 2.2 验证

```bash
where go
# C:\Program Files\Go\bin\go.exe      ← 只能有一条

go version
# go version go1.xx.x windows/amd64
```

`where go` 返回多条说明装了多个版本，从 PATH 里清掉旧的。

## 3. 配置代理

不设代理，`go get` 拉依赖会超时。一条命令：

```bash
go env -w GOPROXY=https://goproxy.cn,direct
```

`direct` = 代理里没有的回源站直连。

### 3.1 环境变量

```bash
go env -w GOPROXY=https://goproxy.cn,direct
go env -w GOSUMDB=sum.golang.org        # 默认值，走代理时会自动转发校验
```

| 变量 | 值 | 说明 |
|---|---|---|
| `GOPROXY` | `https://goproxy.cn,direct` | **必设** |
| `GOSUMDB` | `sum.golang.org` | 默认值，不用动 |
| `GOPRIVATE` | 公司内网域名 | 只有用私有仓库时才设 |

`go env -w` 写入 `%APPDATA%\go\env`，永久生效。撤销用 `go env -u GOPROXY`。

### 3.2 缓存目录

```bash
go env GOPATH GOMODCACHE GOCACHE
```

| 目录 | 默认位置 | 能删吗 |
|---|---|---|
| `GOPATH` | `C:\Users\<你>\go` | 能，下次重新下载 |
| `GOMODCACHE` | `%GOPATH%\pkg\mod` | 能 |
| `GOCACHE` | `%LOCALAPPDATA%\go-build` | 能，会拖慢下次编译 |

```bash
go clean -modcache      # 清依赖（几个 GB）
go clean -cache         # 清编译缓存
```

## 4. 配置编辑器

### 4.1 VS Code

1. 装 https://code.visualstudio.com/ ，装完重启终端
2. `Ctrl+Shift+X` 搜 **Go**，认准发布者 **Go Team at Google**，安装
3. **`Ctrl+Shift+P` → `Go: Install/Update Tools` → 全选 → 确定**

第 3 步不能漏，否则没有补全和跳转：

| 工具 | 作用 |
|---|---|
| `gopls` | 语言服务（补全、跳转、重构） |
| `dlv` | 断点调试 |
| `staticcheck` | 静态检查 |
| `goimports` | 保存时自动整理 import |

失败通常是网络问题，先确认 `GOPROXY` 已设再重试。

### 4.2 推荐设置

`Ctrl+Shift+P` → `Preferences: Open User Settings (JSON)`：

```json
{
  "go.formatTool": "goimports",
  "editor.formatOnSave": true,
  "editor.codeActionsOnSave": {
    "source.organizeImports": "explicit"
  }
}
```

### 4.3 不用 IDE 也行

```bash
gofmt -w .          # 格式化，官方唯一标准
go vet ./...        # 静态检查
```

**`gofmt` 是强制的**，不格式化的代码会被评审退回。

## 5. 第一个项目

### 5.1 建目录

```bash
mkdir C:\code\hello && cd C:\code\hello
```

两条硬要求：**路径全英文**（中文路径会让 cgo、调试器报怪异错误）、**不要放 `C:\Program Files`**（需要管理员权限才能写）。

### 5.2 初始化

```bash
go mod init hello
```

生成 `go.mod`：

```
module hello

go 1.24
```

每个项目只做一次。

### 5.3 写代码

```go
// main.go
package main

import "fmt"

func main() {
	fmt.Println("hello, go")
}
```

### 5.4 运行

```bash
go run .                 # 编译并运行，不留二进制
go build -o hello.exe .  # 生成 exe
./hello.exe
```

### 5.5 项目结构

```
hello/
├── go.mod          # 模块定义
├── go.sum          # 依赖校验和（自动生成，必须提交 git）
├── main.go
└── internal/       # 私有代码，外部无法导入
```

## 6. 第一个测试

测试是语言内置的，不需要装任何东西。

### 6.1 三个文件

```
hello/
├── go.mod
├── calc.go
└── calc_test.go
```

```go
// calc.go
package hello

func Add(a, b int) int { return a + b }
```

```go
// calc_test.go
package hello

import "testing"

func TestAdd(t *testing.T) {
	if got := Add(1, 2); got != 3 {
		t.Errorf("Add(1,2) = %d, want 3", got)
	}
}
```

命名规则，不遵守就不算测试：文件名 `xxx_test.go`、函数名 `TestXxx`、参数 `*testing.T`。

### 6.2 运行

```bash
go test ./...              # 跑全部
go test -v ./...           # 显示每个用例
go test -run TestAdd       # 只跑指定测试
go test -cover ./...       # 覆盖率
```

```
=== RUN   TestAdd
--- PASS: TestAdd (0.00s)
PASS
ok      hello   0.003s
```

退出码 0 = 全过，1 = 有失败。CI 靠退出码判断。

### 6.3 表驱动与基准（进 010）

表驱动测试与基准测试是正式写法——**见 [010 §2 测试与基准](010-错误处理进阶与测试基准.md)**。先掌握 6.1/6.2 的基本跑法即可继续。

## 7. 命令速查

### 7.1 开发循环

```bash
go run .                      # 编译并运行
go build -o app.exe .         # 编译
go test ./...                 # 跑测试
go test -v -run TestFoo ./... # 跑指定测试
gofmt -w .                    # 格式化
go vet ./...                  # 静态检查
```

### 7.2 模块

```bash
go mod init <名字>       # 初始化
go mod tidy              # 整理依赖：删没用的、补缺的
go get pkg@latest        # 拉最新
go get pkg@v1.2.3        # 拉指定版本
go list -m all           # 列出所有依赖
go mod why pkg           # 为什么引了这个包
```

### 7.3 排查

```bash
go env                              # 全部配置
go doc fmt.Println                  # 查文档，不用开浏览器
go build -gcflags='-m' .            # 看逃逸分析
go test -race ./...                 # 竞态检测（需要 gcc）
go tool pprof http://:6060/debug/pprof/profile   # 性能分析
```

### 7.4 交叉编译

```bash
# Git Bash
GOOS=linux GOARCH=amd64 CGO_ENABLED=0 go build -o app .

# PowerShell
$env:GOOS="linux"; $env:GOARCH="amd64"; $env:CGO_ENABLED="0"; go build -o app .
```

生成的二进制拷到 Linux 服务器直接跑，不需要装任何运行时——这是 Go 做运维工具最大的优势。静态编译（塞进 scratch/alpine 镜像）：

```bash
CGO_ENABLED=0 GOOS=linux go build -ldflags="-s -w" -o app .
```

`-s -w` 去掉符号表与调试信息，体积小约 30%。

## 8. 八个坑

### 8.1 `go test -race` 报错需要 gcc

```
go: -race requires cgo
cgo: C compiler "gcc" not found
```

竞态检测依赖 C 运行时。装 mingw-w64，三种方式：

| 方式 | 命令 | 说明 |
|---|---|---|
| **winlibs 便携版** | 解压到 `C:\mingw64`，`C:\mingw64\bin` 加进 PATH | 推荐，不用包管理器 |
| scoop | `scoop install mingw` | 需先装 scoop |
| MSYS2 | `pacman -S mingw-w64-x86_64-gcc` | 组件全但重 |

```bash
gcc --version
CGO_ENABLED=1 go test -race ./...
```

不装也能正常写代码，只是跑不了竞态检测。建议早装，别等遇到并发 bug 才发现。

### 8.2 装完报 `command not found`

终端没重启。关掉所有终端和 VS Code 重新打开。

### 8.3 exe 双击闪退

程序跑完就退出，窗口跟着关。在终端里跑 `./app.exe`。

### 8.4 Defender 拦截新编译的 exe

把工作目录加进排除项：`设置` → `隐私和安全性` → `Windows 安全中心` → `病毒和威胁防护` → `管理设置` → `排除项` → 加 `C:\code`。

不要关闭实时保护，只加目录排除。

### 8.5 中文路径

cgo、调试器、部分第三方工具在中文路径下会报奇怪错误。练习目录用 `C:\code\go`。

### 8.6 CRLF 换行符

```bash
git config --global core.autocrlf input
```

不设的话，仓库里的 shell 脚本在 Linux 上会报 `bad interpreter: /bin/bash^M`。

### 8.7 端口被占

```bash
netstat -ano | findstr :8080
taskkill /PID <PID> /F
```

### 8.8 没跑 go fmt

Go 社区不接受未格式化的代码，提交前必须 `gofmt -w .`（或开 formatOnSave）。

## 9. 检查清单

装完逐项打勾：

| # | 检查 | 命令 | 期望 |
|---|---|---|---|
| 1 | 版本 | `go version` | 输出版本号 |
| 2 | 路径唯一 | `where go` | 只有一条 |
| 3 | 代理 | `go env GOPROXY` | `https://goproxy.cn,direct` |
| 4 | 能编译 | `go run .` | 正常输出 |
| 5 | 能下依赖 | `go get github.com/google/uuid` | 5 秒内成功 |
| 6 | 能跑测试 | `go test ./...` | `ok` |
| 7 | 能格式化 | `gofmt -l .` | 无输出 |
| 8 | 静态检查 | `go vet ./...` | 无输出 |
| 9 | 编辑器补全 | 输入 `fmt.` | 弹出方法列表 |
| 10 | 竞态检测 | `go test -race ./...` | `ok`（需 gcc） |

第 7 项：`gofmt -l .` 列出未格式化的文件，无输出才算合格。建议加进 git pre-commit hook。

### 完成标志

能独立做完这四件事，环境就没问题了：

1. 新建目录 → `go mod init` → `go run` 跑通
2. 写 `_test.go` → `go test -v` 看到 PASS
3. `go get` 第三方库并用上
4. `GOOS=linux go build` 出能在服务器直接跑的二进制

第 4 项是运维场景的核心能力：本地 Windows 开发，扔到 Linux 服务器直接执行。

### 附：升级与卸载

**升级**：下载新版 msi 直接覆盖安装，不用先卸载。依赖缓存保留。

**多版本共存**：

```bash
go install golang.org/dl/go1.21.13@latest
go1.21.13 download
go1.21.13 version
```

**卸载**：设置 → 应用 → 卸载 `Go Programming Language`，然后清残留：

```powershell
Remove-Item -Recurse -Force "$env:USERPROFILE\go"
Remove-Item -Recurse -Force "$env:APPDATA\go"
Remove-Item -Recurse -Force "$env:LOCALAPPDATA\go-build"
```
