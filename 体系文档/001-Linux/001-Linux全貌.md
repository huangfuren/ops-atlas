# Linux 全貌

> **这一册回答**：Linux 板块管什么、十册怎么分工、从哪册进、别的需求去哪找。10 分钟读完，把板块装进一张地图。

> **怎么用**：先看板块地图选册，再按阅读路径走；概念词不认识查 [190 术语表](190-术语表.md)。

## 板块定位

从「机器是什么」到「怎么让它一直稳」。**一册只回答一个问题，一个问题只在一册里答。** 板块分三层：**总览区**（本册 + 方法论 + 全景图）管地图与方法，`110~130` 三个模块目录管具体任务，**附录区**（190 术语表、A 速查、B 差异）垫底备查。

## 阅读路径

- **顺序入门**：111 → 112 → 113 → 114 → 121 → 122，读完就能独立值机；再进阶 131 → 132 → 133 → 134。
- **按任务查**：改配置前先翻对应册的排错路径；命令参数直接查附录 A。
- **救火**：直接看 [002-排障方法论](002-排障方法论.md) 拿思路，再按症状查 [190 术语表](190-术语表.md) 症状反查表定位到册。

## 分界

- **113 与 122**：113 管「谁允许登录、登录后能做什么」，122 管「怎么连、怎么传文件」。
- **121 与「网络」板块**：121 只管单机上网络怎么配、连不通怎么排；TCP/HTTP 原理在「网络」板块。
- **133 与「监控」板块**：133 管登上机器后的性能分析与排障；持续采集、告警、看板在「监控」板块。

## 不在这里

TCP/IP 与 HTTP 原理 → 网络板块 · Prometheus 与告警 → 监控板块 · Nginx/MySQL/Docker/K8s 使用 → 各自板块 · 批量配置 → CICD 板块 · 堡垒机与审计 → 独立文档。
