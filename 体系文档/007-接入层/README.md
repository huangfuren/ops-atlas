# 接入层手册

> **定位**：流量进入系统第一跳的运维文档——Nginx 为主线，HAProxy 与 Keepalived 收尾。000 讲全景与选型，001–007 按功能分册，008 收在高可用双机——每一册对应一类真实任务。  
> **读者**：懂 TCP/HTTP 基本语义（「网络」册水平）、部署过 Web 服务的运维人员，第一次系统管接入层。  
> **口径**：**Nginx 1.24+（开源版，不带商业模块）**；HAProxy 2.8+；Keepalived 2.x；示例环境 CentOS 7 与 Ubuntu 22.04 双系对照（与「Linux」册一致）。  
> **更新**：2026-10-31  
> **术语表**：单独成册 → [00 术语表](00-术语表.md)。75 个术语 · 12 个缩写 · 14 对易混 · 16 条症状反查。

## 阅读约定

1. **开源版口径**：所有功能以 nginx 开源版为准，商业版与三方模块（如主动健康检查）出现处单独注明。
2. **每条配置给验证命令**：`nginx -t` + `curl -I`，改完必验证，验证不过不 reload。
3. **先取证后改配置**：007 册的取证顺序是全册纪律——先看 error log 判断，再动配置。
4. **危险操作先说后果**：`reload` 失败的旧配置回退、`restart` 的断连、证书覆盖，先写后果再写操作。
5. **双系对照**：路径与服务管理给 CentOS 7（`/etc/nginx`，yum）与 Ubuntu 22.04（同路径，apt + sites-enabled）两套。
6. **每册结构统一**：目录 → 正文（每节开头一句承接上文）→ N 个坑 → 排错路径 → 检查清单。
