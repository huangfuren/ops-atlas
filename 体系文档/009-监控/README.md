## 阅读约定

1. **每册结构统一**：目录 → 正文（每节开头一句承接上文）→ N 个坑（表格）→ 检查清单 → 尾链。
2. **先读总览三件套，再进模块目录**：领域概念（四层/三支柱/USE/RED）在 001、002、003，不在工具册重复。
3. **两条工具路线不混读**：容器与云原生主线走 `110-Prometheus/`；物理机、虚拟机、SNMP 网络设备、Windows 走 `120-Zabbix/`。两者共存时，先看 001 的分界。
4. **文字引用带板块名**：册号板块内唯一（111~126），跨板块引用一律「监控 116」式双键，不写裸册号、不写「009-监控」116。
5. **配图两必**：改完必渲染、渲染必目视（PNG 不落盘，全库只留 SVG）；图片一律 `![]()` 嵌入。
