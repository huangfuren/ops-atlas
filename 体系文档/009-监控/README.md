# 监控手册

> **一句话**：可观测性第一支柱——指标监控的领域地图（板块级）与两条工具路线（Prometheus / Zabbix）。  
> **读者**：要为自己的服务建立监控、响应告警的运维/SRE。  
> **口径**：Prometheus 2.x/3.x · Alertmanager 0.27+ · Grafana 10+；Zabbix 6.0 LTS；指标模型遵循 OTel 语义约定（与「链路」互通）。  
> **更新**：2026-11-06  
> **术语表**：板块级 [00 术语表](00-术语表.md)；Prometheus 工具术语见 [prometheus/00 术语表](prometheus/00-术语表.md)；Zabbix 专有词见 [zabbix/00 术语表](zabbix/00-术语表.md)。

## 阅读约定

1. **每册结构统一**：目录 → 正文（每节开头一句承接上文）→ N 个坑（表格）→ 检查清单 → 尾链。
2. **先读 000 与方法论，再进子目录**：领域概念（四层/三支柱/USE/RED）在 000、001 与板块术语表，不在工具册重复。
3. **两条工具路线不混读**：容器与云原生主线走 `prometheus/`；物理机、虚拟机、SNMP 网络设备、Windows 走 `zabbix/`。两者共存时，先看 000 的分界。
4. **文字引用不带目录前缀**：写「监控」006，不写「009-监控」006。
5. **配图两必**：改完必渲染、渲染必目视（PNG 不落盘，全库只留 SVG）；图片一律 `![]()` 嵌入。

## 边界

| 不写什么 | 去哪 |
| --- | --- |
| APM / 分布式追踪深入（OTel/Jaeger/Tempo） | 「链路」板块（000~006） |
| 日志类监控的采集与存储（EFK/Loki） | 「日志」板块 |
| SLO 定义、on-call 纪律、复盘机制 | 「SRE」001~004 |
| 云厂商监控（CloudWatch/阿里云监控等） | 不写——待 015-云平台板块立项后随板块定 |
| 夜莺（N9E）等国产一体化平台对照 | 暂不写，列为后续候选 |
| Zabbix 二次开发、前端主题定制 | 不在运维范围，查官方文档 |
| Windows 服务器监控 | 已由 [zabbix/001~002](zabbix/README.md) 覆盖（agent2） |
