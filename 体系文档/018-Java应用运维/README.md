# Java 应用运维手册

> **一句话**：运维手里的 Java 应用怎么管——JVM 内存与 GC 排障、Tomcat/Spring Boot 交付、日志与线程 dump 分析。  
> **读者**：接手 Java 应用（不管是不是自己写的）的运维/SRE。  
> **口径**：JDK 17 LTS 主线（8.x 存量注记）；视角是"应用的运维"——不教 Java 语法，保证你看得懂参数、抓得住 dump、救得了 OOM。  
> **更新**：2026-11-07  
> **术语表**：单独成册 → [00 术语表](00-术语表.md)。28 个术语 · 8 个缩写 · 10 对易混 · 10 条症状反查。
