# 00 术语表

> **这一文档回答**：某个词是什么意思、两个长得像的概念差在哪、「只知道现象、不知道该翻哪一册」时往哪走。  
> **怎么用**：三种查法——按名字（下面按册分组）、按缩写（缩写速查）、按现象（症状反查）。  
> **只有一句话**：要原理和代码回对应册；这里只保证你「认得出、分得清、找得到」。

## 最容易混的 12 对

| 容易混 | 一句话差别 | 怎么确认 | 册 |
| --- | --- | --- | --- |
| Shell vs Python vs Go | 胶水 <20 行 / 逻辑与生态粘合 20–500 行 / 并发常驻 | 行数与生命周期决定 | 000 |
| pip vs venv | 装包的工具 / 隔离的空间 | `pip -V` 看它属于哪个 venv | 000/001 |
| 全局安装 vs venv 安装 | 污染系统 / 项目隔离 | `which python3` 指向哪 | 001 |
| sys.exit(1) vs raise | 正常失败出口 / 异常传播机制 | 脚本顶层用 exit，函数内用 raise | 001 |
| logging vs print | 有级别有格式可路由 / 只能 stdout | 上生产的一律 logging | 001 |
| shell=False vs True | 参数列表安全 / 经 shell 可注入 | 默认 False，拼接变量时警惕 | 002 |
| subprocess vs paramiko | 本机命令 / 远程 SSH | 目标是不是本机 | 002/003 |

| connect vs read 超时 | 建连等待 / 等响应体间隔 | 挂死多半是 read 没设 | 003 |
| ruff vs black+flake8 | 一个工具干两件事 / 两个工具 | ruff check + ruff format | 006 |

## 按症状反查

| 现象 | 大概是 | 去哪 |
| --- | --- | --- |
| `ModuleNotFoundError: No module named 'requests'` | venv 没激活或包没装进当前环境 | 001 §1.2 |
| `pip install` 报权限错误 | 在往系统 Python 全局装 | 建 venv（001 §1.2） |
| 中文输出乱码 | 编码不一致：文件声明/终端/locale | 002 §2.3 |
| `FileNotFoundError` 但命令明明有 | shell=False 时参数要拆成列表 | 002 §2.1 |
| 用户输入拼进命令被安全扫描 | shell=True 命令注入风险 | 002 §2.1 防线 |
| requests 请求永久挂死 | 没设 timeout | 003 §3.1 |
| 调 API 得到 429/403 | 限流或凭据问题 | 003 §3.5 |
| 脚本手动能跑 cron 不跑 | 环境变量/相对路径/venv 未激活 | 002 §2.6 |
| print 输出顺序错乱/看不到 | 输出缓冲——`flush=True` 或重定向后全缓冲 | 002 §2.6 |
| 脚本重跑把数据改坏 | 非幂等 | 005 §5.4 |
| traceback 一大屏不会读 | 从最后一行往上读，第一行是触发点 | 006 §6.4 |
| 告警脚本风暴时把自己也打挂 | 没有限频 | 005 §5.2 |
