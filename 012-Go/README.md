> **定位**：从零到能用 Go 写出可上生产的服务与运维工具——覆盖环境配置、语言基础、进阶并发、性能调优与生产事故复盘。  
> **读者**：有 Shell 与 Python 基础（本库「Linux」008、「Python」001 水平）的运维人员，第一次系统学 Go。  
> **口径**：Go 1.22+（module 模式）；000 环境配置以 Windows 为主线（本库作者环境），Linux 命令有注记；**标准库优先**，第三方只引运维刚需。

## 阅读约定

1. **Windows 为主线**：000 以 PowerShell 命令为主，Linux 命令有注记。
2. **所有示例可直接跑**：`go run` 即出结果，不依赖未介绍的包。
3. **错误处理不省略**：每段代码的 `if err != nil` 都完整保留——这是 Go 的习惯。
4. **每册结构统一**：目录 → 正文 → 命令速查/坑表 → 检查清单/练习。
